## 2023-10-07 - [Client-Side DoS via LocalStorage Exhaustion]\n**Vulnerability:** User input text fields lacked `maxLength` constraints, allowing for massive strings that could easily fill up the LocalStorage quota or overwhelm the browser rendering engine causing Denial of Service.\n**Learning:** In client-side persistence scenarios (like the poster studio storing states in `localStorage`), unbound text inputs are a vector for quota exhaustion.\n**Prevention:** Add appropriate `maxLength` constraints to all `<input>` and `<textarea>` components saving to local state.
